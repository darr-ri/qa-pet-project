# Чек-лист
## 1. Установка и запуск

- [ ] APK устанавливается без ошибок
- [ ] Приложение запускается ≤ 3 сек
- [ ] Splash screen отображается корректно
- [ ] Первый экран загружается без ошибок
- [ ] Иконка приложения отображается в лаунчере
- [ ] Название приложения корректное

## 2. Основной функционал

### 2.1. Добавление
- [ ] Кнопка «+» открывает форму добавления
- [ ] Поле ввода принимает текст
- [ ] Пустое поле → ошибка или блокировка
- [ ] Товар добавляется в список
- [ ] Список обновляется мгновенно
- [ ] Длинное название обрезается или переносится корректно

### 2.2. Редактирование
- [ ] Тап по товару открывает редактирование
- [ ] Изменения сохраняются
- [ ] Отмена не сохраняет изменения

### 2.3. Удаление
- [ ] Свайп или кнопка удаления работает
- [ ] Подтверждение удаления (если есть)
- [ ] Товар исчезает из списка
- [ ] Удаление последнего товара → пустой список

### 2.4. Отметка «куплено»
- [ ] Чекбокс работает
- [ ] Товар визуально отличается (зачёркнут, серый)
- [ ] Повторный тап снимает отметку

## 3. Сохранение данных

- [ ] Данные сохраняются после закрытия приложения
- [ ] Данные сохраняются после перезагрузки устройства
- [ ] Данные сохраняются после сворачивания
- [ ] Данные не теряются при переключении между приложениями

## 4. Мобильная специфика

### 4.1. Прерывания
- [ ] Входящий звонок → приложение на паузе
- [ ] После звонка состояние восстанавливается
- [ ] SMS-уведомление не ломает приложение
- [ ] Будильник не сбрасывает данные

### 4.2. Поворот экрана
- [ ] Портретная ориентация
- [ ] Ландшафтная ориентация
- [ ] Вёрстка не ломается при повороте
- [ ] Данные не теряются при повороте

### 4.3. Жесты
- [ ] Скролл работает
- [ ] Свайп для удаления (если есть)
- [ ] Long tap (если есть контекстное меню)
- [ ] Pinch-to-zoom (если применимо)

### 4.4. Кнопки устройства
- [ ] Кнопка «Назад» работает корректно
- [ ] Кнопка «Домой» сворачивает приложение
- [ ] Кнопка «Недавние» показывает приложение

### 4.5. Сеть
- [ ] Работа без интернета (offline)
- [ ] Переключение Wi-Fi → мобильные данные
- [ ] Потеря сети во время работы

### 4.6. Батарея и ресурсы
- [ ] Низкий заряд батареи (режим экономии)
- [ ] Приложение не расходует много батареи
- [ ] Приложение не перегревает устройство

## 5. UI/UX

- [ ] Шрифты читаемы
- [ ] Кнопки не перекрывают друг друга
- [ ] Отступы одинаковы
- [ ] Иконки корректны
- [ ] Сообщения об ошибках понятны
- [ ] Тёмная тема (если поддерживается)
- [ ] Размер шрифта в системе меняет отображение (проверить)
