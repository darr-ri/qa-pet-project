## 3. Функциональные требования

### 3.1. Авторизация
1.Пользователь может войти с валидными логином и паролем. 
2.При пустых полях система показывает сообщение «Username is required».
3.При неверных данных — «Username and password do not match».
4.После входа пользователь попадает на /inventory.html.

### 3.2. Каталог товаров
1.Отображается 6 товаров.
2.У каждого товара есть название, цена, изображение, кнопка Add to cart.
3.Сортировка работает по 4 вариантам (Name A-Z, Name Z-A, Price low-high, Price high-low).

### 3.3. Корзина
1.Кнопка Add to cart меняется на Remove после добавления.
2.Счётчик корзины увеличивается при добавлении.
3.В корзине отображаются все добавленные товары с ценами.
4.Товар можно удалить из корзины.

### 3.4. Оформление заказа
1.Checkout требует First Name, Last Name, Zip. 
2.При пустых полях — ошибка.
3.На шаге 2 отображается итоговая сумма. 
4.После Finish — сообщение «Thank you for your order!».

### 3.5. API ReqRes
1.POST /api/login с валидными данными возвращает 200. 
2.POST /api/login без пароля — 400 и сообщение об ошибке.
3.GET /api/users?page=2 возвращает 200 и список пользователей.
4.GET /api/users/23 возвращает 404 (пользователь не найден).
5.DELETE /api/users/2 возвращает 204.
## 4. Нефункциональные требования

### 4.1. Производительность
1.Страница логина загружается ≤ 3 сек.
2.API отвечает ≤ 1 сек.

### 4.2. Удобство (Usability)
1.Сообщения об ошибках на английском, понятны пользователю.

### 4.3. Совместимость
1.Работает в Chrome, Firefox.
2.Адаптивность под экраны 1280px+.

### 4.4. Безопасность
1.Пароль скрыт символами •.

### 4.5. Мобильное
1.Поворот экрана не ломает вёрстку.
2.Данные сохраняются после сворачивания приложения.
## 5. Границы тестирования

### Входит в тестирование:
- Функциональное тестирование веба, API, мобильного
- UI-тестирование
- Кросс-браузерное (Chrome, Firefox)
- Тестирование API в Postman
- Мобильное тестирование на эмуляторе Android
- Негативные сценарии

### Не входит:
- Автоматизация (это ручной проект)
- Нагрузочное тестирование
- Тестирование на реальных устройствах iOS
- Тестирование backend-инфраструкт
