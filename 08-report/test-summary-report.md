## 3. Объём тестирования

### 3.1. Входит в тестирование
- Функциональное тестирование SauceDemo: авторизация, каталог,
  корзина, checkout, сортировка, меню.
- UI/UX-тестирование.
- Кросс-браузерное тестирование (Chrome, Yandex).
- Тестирование API Swagger: аутентификация, CRUD, ошибки.
- Негативные и граничные сценарии.
- Базовые проверки безопасности.
- SQL-проверки целостности данных.

### 3.2. Не входит
- Автоматизация (проект ручной).
- Нагрузочное тестирование.
- Локализация (кроме английского).

### 4. Найденные баги

### 4.1 Критичные баги (Blocker + Critical)
- BUG-003: Кнопка "Add to cart" не добавляет товар или добавляет не тот товар
### 4.2 Значимые (Major)
- BUG-001: Изображения всех товаров одинаковые и не соответствуют названиям
- BUG-002: При выборе сортировки "Name (Z to A)", при выходе из корзины данная сортировка слетает
- BUG-005: Форма About не производит переход на внешний ресурс
- BUG-API-001: POST /api/login возвращает 500 вместо 400
- ### 4.3 Мелкие (Minor + Trivial)
- BUG-004: Форма Checkout позволяет отправить данные с пустым Zip

## 5. Выводы

для standard_user, но содержит серьёзные дефекты для problem_user.
