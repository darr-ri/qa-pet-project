## 1. Аутентификация

### TC-API-001. Успешный логин
**Приоритет:** High
**Метод:** POST
**URL:** /api/login

**Body:**
```json
{
  "email": "eve.holt@reqres.in",
  "password": "cityslicka"
}
```

**Ожидаемый результат:**
- Код 200
- Тело: `{ "token": "..." }`
- Content-Type: application/json
- Время ответа ≤ 1 сек
