## 3. CRUD

### TC-API-009. Обновление пользователя (PUT)
**Приоритет:** Medium
**Метод:** PUT
**URL:** /mythology{id}

**Body:**
```json
{
  "name": "Посейдон999",
  "category": "Боги",
  "desc": "Бог морей и землетрясений.",
  "img": "https://images.unsplash.com/photo-1503152394-c571994fd383"
}
```
**Ожидаемый результат:**
- Код 200
- updatedAt присутствует
- name и category обновлены

**Фактический результат:**
- Код 200
- Тело
```json
{
"id": 32,
"name": "Посейдон999",
"category": "Боги",
"desc": "Бог морей и землетрясений.",
"img": "https://images.unsplash.com/photo-1503152394-c571994fd383"
}
```
**Статус:** Passed
