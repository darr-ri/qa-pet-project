# QA Pet Project — Комплексное тестирование

## О себе
Начинающий ручной тестировщик, закончила курс "ручной тестровщк" на платформе skillfactory

## Что внутри
- Тестирование веб-приложения SauceDemo
- Тестирование API ReqRes
- Мобильное тестирование
- SQL-запросы

## Инструменты
Jira, Postman, DevTools, Android Studio, adb, Git, Google Sheets

## Структура репозитория
- `01-requirements/` — анализ требований
- `02-test-plan/` — тест-план
- `03-checklists/` — чек-листы
- `04-test-cases/` — тест-кейсы
- `05-bug-reports/` — баг-репорты
- `06-screenshots/` — скриншоты
- `07-postman/` — коллекция Postman
- `08-sql/` — SQL-запросы
- `09-report/` — итоговый отчёт
