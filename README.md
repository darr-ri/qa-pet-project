# QA Pet Project — Комплексное тестирование
Портфолио начинающего ручного тестировщика: полный цикл тестирования
веб-приложения, API  — от анализа требований до итогового отчёта.
## О себе
Начинающий ручной тестировщик, закончила курс "ручной тестровщик" на платформе skillfactory.

**Навыки:**
- Теория тестирования
- Ручное тестирование (функциональное, нефункциональное)
- Тест-дизайн (техники тест-дизайна,чек-листы, тест-кейсы, баг-репорты)
- Тестирование API (Postman)
- Основы SQL
- Инструменты: Jira, DevTools, SQLite Online

## О проекте

В рамках пэт-проекта проведено комплексное тестирование объектов:

| Объект       | Тип | Что тестировалось |
|--------------|-----|-------------------|
| SauceDemo    | Веб-приложение | Авторизация, каталог, корзина, checkout, сортировка |
| API Swagger  | REST API | Аутентификация, CRUD, обработка ошибок |

**Цель:** продемонстрировать полный цикл работы тестировщика —
от анализа требований до итогового отчёта.

## Структура репозитория
- ```01-requirements/``` — анализ требований
- ```02-test-plan/``` — тест-план
- ```03-checklists/``` — чек-листы
- ```04-test-cases/``` — тест-кейсы
- ```05-bug-reports/``` — баг-репорты
- ```06-screenshots/``` — скриншоты
- ```07-sql/``` — SQL-запросы
- ```08-report/```— итоговый отчёт
